# 📘 Plano de Estudo: Estruturação de Aplicações na Nuvem com Azure

## 🎯 Objetivo Geral  
Aprender a estruturar, desenvolver, publicar e monitorar aplicações modernas em nuvem usando o Microsoft Azure, com foco em .NET, ReactJS e SQL Server.

---

## 📅 Cronograma de Aprendizado - 8 Semanas

### **Semana 1: Fundamentos do Azure**
- Conceitos de IaaS, PaaS, SaaS
- Regiões e Zonas de Disponibilidade
- Grupos de recursos e gerenciamento básico

📚 **Recursos:**
- [Microsoft Learn - Azure Fundamentals](https://learn.microsoft.com/en-us/training/paths/azure-fundamentals/)
- [AZ-900: Microsoft Certified: Azure Fundamentals](https://learn.microsoft.com/en-us/certifications/azure-fundamentals/)

---

### **Semana 2: Azure Portal, CLI e ARM Templates**
- Navegação no portal
- Uso do Azure CLI
- Introdução a ARM Templates e Bicep

📚 **Recursos:**
- [Microsoft Learn - Azure CLI](https://learn.microsoft.com/en-us/training/modules/introduction-azure-cli/)
- [Bicep para Infra como Código](https://learn.microsoft.com/en-us/azure/azure-resource-manager/bicep/)

---

### **Semana 3: Hospedagem de Aplicações Web (App Services)**
- Deploy de aplicação ASP.NET no Azure App Service
- Configuração de slots de deployment
- CI/CD básico com GitHub Actions ou Azure DevOps

📚 **Recursos:**
- [Deploy .NET apps to Azure App Service](https://learn.microsoft.com/en-us/azure/app-service/)
- [Tutorial com GitHub Actions](https://learn.microsoft.com/en-us/azure/app-service/deploy-github-actions)

---

### **Semana 4: Banco de Dados no Azure**
- Azure SQL Database: criação, escalabilidade, segurança
- Backup, Restore e Geo-Replicação
- Acesso via Entity Framework

📚 **Recursos:**
- [Microsoft Learn - Azure SQL](https://learn.microsoft.com/en-us/training/modules/introduction-to-azure-sql/)
- [Entity Framework com Azure SQL](https://learn.microsoft.com/en-us/ef/core/providers/sql-server/azure-sql)

---

### **Semana 5: React + Azure**
- Hospedando SPA com Azure Static Web Apps
- Configuração de CI/CD para front-end
- Comunicação entre React e APIs no Azure

📚 **Recursos:**
- [Azure Static Web Apps](https://learn.microsoft.com/en-us/azure/static-web-apps/)
- [Tutorial: React + Azure Functions](https://learn.microsoft.com/en-us/azure/static-web-apps/add-api)

---

### **Semana 6: Azure Functions e Serverless**
- Azure Functions com C#
- Triggers (HTTP, Timer, Queue)
- Durable Functions (conceito)

📚 **Recursos:**
- [Microsoft Learn - Azure Functions](https://learn.microsoft.com/en-us/training/modules/create-serverless-logic-with-azure-functions/)
- [Exemplos com C#](https://learn.microsoft.com/en-us/azure/azure-functions/functions-dotnet-class-library)

---

### **Semana 7: Segurança e Monitoramento**
- Azure Key Vault
- Application Insights
- Azure Monitor + Logs

📚 **Recursos:**
- [Azure Key Vault](https://learn.microsoft.com/en-us/azure/key-vault/)
- [Application Insights](https://learn.microsoft.com/en-us/azure/azure-monitor/app/app-insights-overview)

---

### **Semana 8: Projeto Final**
> **Plataforma de controle de dados com front React, backend em .NET e SQL no Azure.**
- Front hospedado no Static Web Apps
- Backend em App Services
- DB com Azure SQL
- Integrações com Key Vault e Application Insights
